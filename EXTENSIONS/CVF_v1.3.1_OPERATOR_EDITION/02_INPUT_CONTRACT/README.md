Input Contract – Operator Edition

Mục đích

Input Contract tồn tại để:

khóa trách nhiệm execution về phía AI

loại bỏ “hiểu sai ý”

ngăn operator vô tình can thiệp logic

Trong CVF:

Input là luật.
Output chỉ có thể đúng hoặc sai so với luật đó.

Operator cần hiểu gì?

Input không phải prompt

Input không phải hội thoại

Input không phải nơi giải thích suy nghĩ

Input là một hợp đồng tĩnh giữa Operator và AI.

Input Contract gồm mấy phần?

Ở mức tối thiểu, input hợp lệ phải có 4 khối:

Objective

Scope

Output Contract

Constraints

Thiếu bất kỳ khối nào → input không hợp lệ.

Khi nào Input bị coi là sai?

Có mô tả cách làm

Có gợi ý chiến lược

Có tiêu chí đánh giá cảm tính

Có yêu cầu “linh hoạt”, “sáng tạo”

→ Những input này tước trách nhiệm của AI.
