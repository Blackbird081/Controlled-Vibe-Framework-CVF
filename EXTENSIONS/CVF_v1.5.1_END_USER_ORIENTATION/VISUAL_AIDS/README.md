# VISUAL_AIDS — Interactive Guides for End Users

> **Mục tiêu:** Công cụ trực quan giúp end user hiểu và sử dụng CVF mà không cần đọc nhiều tài liệu.

---

## 📁 Danh sách files

| File | Mô tả | Cách dùng |
|------|-------|-----------|
| `process_flowchart.html` | Sơ đồ 5 bước CVF interactive | Mở bằng browser, click từng bước |
| `quick_reference_card.html` | Thẻ tham khảo nhanh (1 trang) | Mở bằng browser, in ra (Ctrl+P) |
| `template_gallery.html` | Gallery 8 templates với filter | Mở bằng browser, chọn template |

---

## 🚀 Hướng dẫn sử dụng

### 1. Process Flowchart

- **Mục đích:** Hiểu quy trình CVF 5 bước
- **Cách dùng:** Double-click file → mở trong Chrome/Edge → click từng bước để xem chi tiết
- **Tính năng:** Interactive, dark theme, animation

### 2. Quick Reference Card

- **Mục đích:** Cheat sheet 1 trang để dán lên bàn làm việc
- **Cách dùng:** Mở file → Ctrl+P → In ra giấy A4
- **Tính năng:** Printable, đầy đủ info cần thiết

### 3. Template Gallery

- **Mục đích:** Xem trước tất cả templates có sẵn
- **Cách dùng:** Mở file → Lọc theo category → Click template để xem chi tiết
- **Tính năng:** Filter, modal detail, responsive

---

## 💡 Tips

1. **Cho người mới:** Bắt đầu với `process_flowchart.html`
2. **Để tra cứu nhanh:** In `quick_reference_card.html`
3. **Trước khi dùng CVF:** Xem `template_gallery.html` để chọn template phù hợp

## 🔧 Yêu cầu kỹ thuật

- **Không cần server:** Mở trực tiếp file HTML
