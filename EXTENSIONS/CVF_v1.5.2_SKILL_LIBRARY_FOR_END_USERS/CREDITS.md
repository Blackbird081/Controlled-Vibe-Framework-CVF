## 🔄 Quy trình Transformation

Mỗi skill được chuyển đổi qua quy trình sau:

1. **Phân tích nguồn gốc** — Đọc và hiểu skill gốc
2. **Trích xuất criteria** — Lấy các tiêu chí đánh giá ẩn
3. **CVF Format** — Chuyển sang Form + Checklist + Common Failures
4. **End User Focus** — Điều chỉnh ngôn ngữ cho người không code
5. **Review** — Kiểm tra và test với End User thật
