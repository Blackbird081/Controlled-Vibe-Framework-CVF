## ✅ Expected Output

**Kết quả bạn sẽ nhận được:**

- JD hoàn chỉnh, professional
- Cấu trúc rõ ràng, dễ đọc
- Phù hợp để đăng tuyển

**Cấu trúc output:**

```
1. Company Overview (ngắn gọn)
2. Role Summary
3. Key Responsibilities (5-8 bullet points)
4. Requirements
   - Must have
   - Nice to have
5. What We Offer
6. How to Apply
```

---

## 🔍 Cách đánh giá

**Checklist Accept/Reject:**

- [ ] Rõ ràng về scope và responsibilities
- [ ] Requirements phù hợp với level
- [ ] Không có bias (gender, age, nationality)
- [ ] Đủ thông tin để ứng viên quyết định apply
- [ ] Tone phù hợp văn hóa công ty
- [ ] Không quá dài (max 1 trang A4)

**Red flags (cần Reject):**

- ⚠️ Requirements quá generic hoặc quá nhiều
- ⚠️ Responsibilities không clear
- ⚠️ Có bias language ("dynamic young team")
- ⚠️ Không mention level/experience rõ ràng

---

## ⚠️ Common Failures

| Lỗi thường gặp | Cách phòng tránh |
|----------------|------------------|
| JD quá generic | Cung cấp context công ty cụ thể |
| Requirements không thực tế | So sánh với JD tương tự trên thị trường |
| Thiếu info về culture/benefits | Thêm phần What We Offer |
| Quá dài, khó đọc | Giới hạn 5-8 bullets mỗi section |

---

## 💡 Tips

1. **Benchmark trước** — Xem JD tương tự trên LinkedIn/TopCV
2. **Focus must-have** — Đừng list quá nhiều nice-to-have
3. **Dùng action verbs** — "Lead", "Build", "Drive" thay vì "Responsible for"
4. **Include salary range** — Tăng response rate 30-50%
5. **Review với hiring manager** — Đảm bảo aligned với team

## 📊 Ví dụ thực tế

### Input mẫu

```
Vị trí: Senior Frontend Developer
Level: Senior, 4+ năm kinh nghiệm
Department: Engineering
Responsibilities: Build web app, code review, mentor junior
Requirements: React, TypeScript, testing
Benefits: Remote, 13th salary, learning budget
```

### Output mẫu

```
SENIOR FRONTEND DEVELOPER
Engineering Team | Remote-first

About Us:
[Company] is building the next generation of...

The Role:
You'll lead frontend development for our core product...

Key Responsibilities:
• Build and maintain React-based web applications
• Conduct code reviews and ensure code quality
• Mentor junior developers
• Collaborate with design and product teams
• Contribute to technical decisions

Requirements:
Must have:
• 4+ years of frontend development experience
• Strong React and TypeScript skills
• Experience with testing (Jest, React Testing Library)
• Good communication skills

Nice to have:
• Experience with Next.js
• Knowledge of design systems

What We Offer:
• Remote-first culture
• 13th month salary
• $1000/year learning budget
• Modern tech stack

How to Apply:
Send your CV to careers@company.com
```

### Đánh giá

- ✅ Clear responsibilities
- ✅ Realistic requirements
- ✅ No bias language
- ✅ Good structure
- **Kết quả: ACCEPT**
