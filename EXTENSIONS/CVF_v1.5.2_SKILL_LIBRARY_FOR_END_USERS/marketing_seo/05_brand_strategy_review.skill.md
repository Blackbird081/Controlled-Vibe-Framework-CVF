## ✅ Checklist Đánh giá

### Voice Attributes (Tính cách)

- [ ] Voice attributes có được define rõ ràng (3-5 adjectives)?
- [ ] Có "We are/We are not" spectrum?
- [ ] Voice có phù hợp với target audience?
- [ ] Voice có differentiate từ competitors?

### Tone Variations

- [ ] Có guidance cho different contexts?
- [ ] Customer support tone vs Marketing tone?
- [ ] Social media tone vs Website tone?
- [ ] Happy path vs Error/apology tone?

### Language Guidelines

- [ ] Vocabulary list (use/don't use)?
- [ ] Jargon và technical terms policy?
- [ ] Inclusive language guidelines?
- [ ] Grammar và punctuation rules?

### Content Consistency

- [ ] Website copy consistent?
- [ ] Social media consistent?
- [ ] Email communications consistent?
- [ ] Customer support consistent?
- [ ] Advertising consistent?

### Documentation

- [ ] Voice guidelines documented?
- [ ] Examples for each guideline?
- [ ] Do/Don't examples?
- [ ] Easy to access for team?

## ⚠️ Lỗi Thường Gặp

| Lỗi | Impact | Fix |
|-----|--------|-----|
| **No defined voice** | Inconsistent brand | Create voice attributes |
| **Too generic** | No differentiation | Be more specific và unique |
| **Multiple writers, no guide** | Fragmented voice | Create style guide |
| **Formal everywhere** | Low engagement | Adapt tone to channel |
| **Copying competitors** | No identity | Find unique voice |
| **Ignoring context** | Inappropriate tone | Tone guidelines per context |

## 💡 Tips & Examples

### Voice Attribute Template

```
We are:           We are not:
─────────────────────────────
Friendly     →    Casual/Sloppy
Expert       →    Condescending
Helpful      →    Pushy
Confident    →    Arrogant
Playful      →    Unprofessional
```

### Brand Voice Examples

**Mailchimp** (Friendly, Weird, Expert):

```
"High fives! Your campaign is on its way."
vs generic: "Your campaign has been sent successfully."
```

**Apple** (Simple, Confident, Minimal):

```
"This changes everything. Again."
vs generic: "Introducing our new product with many features."
```

**Slack** (Friendly, Clear, Playful):

```
"You're all caught up! Time for a coffee break ☕"
vs generic: "No new messages."
```

### Voice Documentation Template

```markdown
# [Brand] Voice Guidelines

## Voice Attributes
1. **[Attribute 1]** - Description + examples
2. **[Attribute 2]** - Description + examples
3. **[Attribute 3]** - Description + examples

## Tone by Context
- Marketing: [Description]
- Support: [Description]
- Social: [Description]
- Error Messages: [Description]

## Language Rules
- ✅ Use: [word list]
- ❌ Avoid: [word list]

## Examples
| Context | ❌ Don't | ✅ Do |
|---------|---------|-------|
| Welcome | "Hello user" | "Hey [Name]! 👋" |
| Error | "Error 404" | "Oops! Page not found" |
```

### Quick Voice Check

- Read content aloud - does it sound like your brand?
- Show to someone unfamiliar - can they identify the brand?
- Compare across channels - is it consistent?

```
## Do / Don't
Do: "Kiểm kho trong 30 giây"

Tagline: "Kiểm kho nhanh, sai số thấp."
CTA: "Dùng thử 14 ngày"
UI microcopy: "Đã lưu phiếu nhập • 2s"
```
