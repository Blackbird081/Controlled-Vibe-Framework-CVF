# Governance model

CVF controls are proportionate to the work. The operator sets the goal, scope, spending limit and stop conditions, and accepts the result. Agents choose how to work within those limits and provide evidence and remaining work.

## Stages and authority

The five core stages are understand, plan, build, check and close. Planning includes the Local DESIGN, SPEC and WORK ORDER decisions. The complete chain is INTAKE → DESIGN → SPEC → WORK ORDER → BUILD → REVIEW → FREEZE. See the [work lifecycle](lifecycle.md).

Authority depends on the intersection of current phase, role and risk, plus applicable Local rules. A role name or setting alone grants no permission. When an action exceeds its authority, the agent stops and escalates the decision. See the [risk model](risk-model.md).

## Review and handoff

Set a reviewable goal and expected evidence before work begins. Check the result, unresolved issues and owned remainder before acceptance. The operator decides changes to direction, spending authority and external effects.
