# CVF quick reference

## Write a specification

1. Open CVF Web and choose a result on Home, or open a [reusable form in the Local workspace](../governance/skill-library/registry/user-skills/INDEX.md).
2. Describe the goal, the input, the result you want, and what the agent is allowed to read or change.
3. Download the specification from Home, or save your filled-in Local form. Give it to the agent responsible for the work.
4. Review the result against the acceptance checks you wrote. Leave any required decision pending until the authorized person responds.

For example, ask for a weekly sales summary with totals by product, using the attached spreadsheet. Say which date range to include, how to handle missing values, and whether the agent may edit the source file.

## Check the scope before work starts

Use the [quick orientation](guides/CVF_QUICK_ORIENTATION.md) for the decisions from intake to completion. For actual actions, use the [phase authority matrix](../governance/toolkit/03_CONTROL/CVF_PHASE_AUTHORITY_MATRIX.md). Ask for the required approval before any work that needs it.
