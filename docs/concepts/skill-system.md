# Skill system

## Choose a result

Choose a template on Web Home to write a specification. In the Local workspace, use an [end-user form](../../governance/skill-library/registry/user-skills/INDEX.md) when you need a reusable input and output structure. Give the receiving agent your goal, inputs, allowed scope and an example of an acceptable result. Check the result against those requirements before accepting it.

## Find a package for an agent

The [agent package index](../../docs/reference/agent_system_skills/generated/skill-index.json) shows package status, certification and locations. Read the entry and the package's usage limits before asking an agent to use it. The work still follows the approved scope and the [phase authority matrix](../../governance/toolkit/03_CONTROL/CVF_PHASE_AUTHORITY_MATRIX.md).

## Interpret the existing registry

The [skill-library governance layer](../../governance/skill-library/README.md) holds the USR and AGT records and their validation tools. Use the current catalogs for discovery and the registry documentation to interpret those records and their assessment scores.
